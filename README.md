# Medición

Proyecto escolar para registrar tareas y evaluar el rendimiento de cajeros. Usa Node.js, PostgreSQL y páginas HTML, CSS y JavaScript.

## Ejecutar

1. Instala Node.js 24 o posterior, pnpm y PostgreSQL.
2. Copia `.env.example` a `.env`, cambia `PGPASSWORD` y define `PGADMIN_PASSWORD` en la terminal.
3. Ejecuta `pnpm install`, `pnpm setup`, `pnpm seed` y `pnpm start`.
4. Abre <http://127.0.0.1:3000>.

Los datos cargados para la demostración son ficticios.
